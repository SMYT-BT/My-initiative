## 実装内容（課題内容）

開発の現場にて、GitHub が使えることは必須条件に近くあり、PR（プルリクエスト）をできるようにと、本課題を受領。
本課題の対応として、以下のように２回実施。

・１回目：PRを作成し、PRを実施。

・２回目：１回目のPRを使い、再度PRを実施。
